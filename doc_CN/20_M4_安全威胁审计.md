# M4 安全威胁审计

状态：内部候选通过；公开 RC 仍受签名与安装矩阵门禁约束  
审计日期：2026-09-05  
目标：XDRate Music `0.2.0`，Windows 10/11 x64，Tauri 2

## 1. 执行摘要

本轮对存档、图片、原生文件、WebView 导航、Tauri 权限、离线承诺与依赖供应链进行了威胁建模和代码级复核。已修复导入封面可伪装 MIME、上传图片只信任浏览器 MIME、字符串 PNG 源可触发远程获取、已有文件可经符号链接/重解析点绕过，以及生产 WebView 缺少显式导航拒绝策略等边界问题。

结论：未解决高危代码缺陷为 0，可供受控内部候选测试；公开 `0.2.0-rc.1` 不得发布，直到 Authenticode 签名、RFC 3161 时间戳、正式图标和干净 Windows 10/11 安装矩阵全部通过。

## 2. 范围与攻击面

- 输入：`.xdrate.json`、JPEG/PNG/WebP、表单文字、PNG 导出数据；
- 信任边界：React WebView ↔ Tauri IPC ↔ Rust 原生文件层 ↔ 用户选择的本地路径；
- 本地状态：自动草稿、恢复快照、最近文件、当前文件句柄；
- 发布面：npm/Rust 依赖、NSIS 安装器、签名证书、GitHub Releases；
- 明确不含：账号、服务器、云同步、遥测、远程素材、内置更新。

## 3. STRIDE 与攻击路径结论

| 威胁     | 主要路径                     | 控制与证据                                                                   | 余留风险                                                             |
| -------- | ---------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 伪造     | 伪造图片 MIME/扩展名         | 上传与存档封面均校验 PNG/JPEG/WebP MIME、Base64 结构和魔数                   | 截断但有合法文件头的图片可能进入渲染并显示失败；不会执行代码，低风险 |
| 篡改     | 覆盖已有存档时中断           | 同目录临时文件、刷新落盘、Windows 原子替换；失败测试证明旧目标保留           | 文件系统/杀毒软件的极端行为需真实机矩阵覆盖                          |
| 抵赖     | 无账号且无审计后端           | 保存状态、当前路径和错误结果在本地明确呈现                                   | 不提供不可抵赖审计，符合单机离线产品定位                             |
| 信息泄露 | 远程请求、遥测、远程字体     | CSP、本地资源、E2E 外联断言、无 HTTP/updater 权限                            | 操作系统和 WebView 自身流量不属于应用业务流量                        |
| 拒绝服务 | 超大 JSON/PNG、长文本        | JSON 16 MiB、上传图片 10 MiB、原生 PNG 64 MiB、Zod 与有界读取                | 合法上限内仍可能短时占用内存，低风险                                 |
| 权限提升 | shell/进程/任意文件/远程导航 | 能力仅限主窗口与三个必要权限；无 shell、process、HTTP、updater；导航默认拒绝 | 用户主动在系统对话框中选择的位置仍受其账户权限支配                   |

PASTA 攻击链复核结果：攻击者可控内容必须先经过文件选择与大小限制，再经过格式/Schema 校验；通过后的数据只能进入纯展示和限定文件命令，无法抵达命令执行、任意网络或 HTML 注入接收点。当前未发现从不可信输入到代码执行或越权写入的完整路径。

## 5. 红队验证

- 以 SVG/HTML/远程 URL/伪 PNG 作为存档封面：均被拒绝；
- 以 SVG 内容伪装 `image/png` 上传：魔数不符，被拒绝；
- 将远程 HTTPS URL 作为桌面 PNG 源：在 `fetch` 和 IPC 前被拒绝；
- 使用 `../outside` 和 Windows 绝对路径作为建议文件名：只保留安全 basename；
- 尝试远程 HTTPS、`file:` 与 `javascript:` 顶层导航：原生策略拒绝；
- 尝试引入 shell、HTTP、updater 权限或通配 CSP：项目安全检查失败。

## 6. 蓝队加固与监测

- `npm run check:security` 固化 CSP、能力、URL、导航、执行接收点和高置信秘密门禁；
- `npm run check:desktop-config` 冻结标识、元数据、权限与导航配置；
- GitHub Actions 分离 Web、安全、Windows 原生与视觉结果，任一失败均阻止候选门禁；
- 应用不采集遥测；故障恢复只保留本地状态，不把用户正文上传或写入发布日志；
- 公开产物以签名验证、SHA-256 清单和干净快照测试承担发布侧检测。

## 7. 依赖与风险接受

- `npm audit --omit=dev --audit-level=high`：0 个漏洞；
- `cargo audit --file src-tauri/Cargo.lock`：0 个漏洞，17 条 allowed warnings；
- warnings 主要来自非 Windows 的 GTK3 传递依赖、若干停止维护的过程宏/Unicode 包，以及 `glib 0.18.5` 的 RustSec 警告。它们不进入当前 Windows x64 目标产物路径，但仍属于供应链余留风险；接受范围仅限 `0.2.0` Windows x64 内部候选，并要求升级 Tauri/传递依赖时复审。
- Save As 所在目录由用户在系统对话框中明确选择；程序拒绝已有重解析点目标，但不尝试替代操作系统解析整个用户选定父路径。该行为按用户授权边界接受为低风险。
