## 1. 目标与边界

M2.1 在进入正式卡片保存 M3 前，完成两个本地连续性能力：自动恢复用户最后一次输入，以及把当前完整内容保存为可重复套用的用户模板。首次初始化模板目录时创建普通《海棠仙》模板；若此时没有有效最近草稿，编辑器直接把它用作开局内容。

本工作包不改变评分算法、Archive Schema v2、桌面评分结构模板、封面压缩、卡片比例或 JSBridge 权限。作为 M2.1 的界面收束，小工具允许增删 1–12 个正向加分项，并以中性评分术语替代图标外形描述。模板“长期保存”仅表示在同一小工具本地存储未被清理时跨关闭/重开保留，不是云备份或永久存储承诺。

## 2. 已冻结产品行为

### 2.1 启动顺序

```text
读取最近草稿、模板目录和一次性播种标记
  ├─ 最近草稿合法：恢复最近草稿（最高优先级）；未播种则只创建普通《海棠仙》模板
  ├─ 无草稿且未播种：创建并套用普通《海棠仙》模板，再记录播种完成
  ├─ 无草稿且已播种：创建空白简易草稿，不重建已删除/改名的模板
  ├─ 草稿损坏：隔离并警告；根据播种状态选择首次模板或空白草稿
  └─ 存储不可用：在内存载入《海棠仙》开局内容并显示未保存状态
```

《海棠仙》只在播种标记不存在时创建一次，创建后没有特殊权限。改名或删除不得清除播种标记，因此正常重开不会恢复它；只有清除全部小工具本地数据后才重新视为首次初始化。首次自动套用不弹确认；用户之后主动套用任意内容模板会替换当前编辑内容，必须确认。

### 2.2 最近草稿

- 保存当前全部文本、评分、理由、模式和作品字段，沿用 300 ms 防抖；页面隐藏/关闭前再尽力同步保存一次。
- 保存成功显示本地保存状态；失败保留内存编辑内容，不能误报成功。
- 最近草稿与模板目录使用不同键并独立校验，任一损坏不得清空另一类数据。
- M2 的压缩封面仍只在内存以 Blob URL 使用，不写入最近草稿或内容模板。

### 2.3 内容模板

- 首次创建的《海棠仙》与其他内容模板完全相同，可以套用、改名、覆盖或删除。
- 用户可执行“将当前内容存为模板”、套用、重命名和删除；不存在“内置/只读”状态。
- 模板名去除首尾空白后为 1–40 字符；同名比较使用规范化后的名称。同名覆盖与删除需二次确认。
- 最多 20 个内容模板（包含首次创建的《海棠仙》），整个目录序列化后不超过 512 KiB；超限或配额失败不修改旧目录。
- 列表统一按最近更新时间降序，不固定置顶任何模板。
- 首版不导入/导出模板文件、不跨设备同步、不把封面写入模板。

## 4. 数据与实现方案

### 4.1 存储键

| 数据               | 键                                               | 版本    |
| ------------------ | ------------------------------------------------ | ------- |
| 最近草稿           | `xdrate.music.minitool.workspace.v1`             | 沿用 v1 |
| 内容模板目录       | `xdrate.music.minitool.content-templates.v1`     | 新增 v1 |
| 一次性模板播种标记 | `xdrate.music.minitool.content-template-seed.v1` | 新增 v1 |

目录项使用 `format: 'xdrate-music-minitool-content-template'`、`schemaVersion: 1`、稳定 ID、名称、ISO 创建/更新时间和无封面的 `MusicRatingDraft`。源码常量只负责首次播种；目录成功写入后再写独立播种标记。改名或删除只更新目录，不清除标记；初始化重试发现稳定种子 ID 已存在时不得创建重复项。

### 4.2 模块划分

```text
src/minitool/fixtures/haitangxianTemplate.ts
  └─ 仅用于首次播种、冻结、无封面的完整夹具

src/minitool/contentTemplates.ts
  ├─ 严格校验与无封面深拷贝
  ├─ load / create / rename / delete / replace
  └─ 数量、名称与 512 KiB 配额门禁

src/minitool/main.tsx
  ├─ 启动优先级与状态提示
  └─ 模板列表、保存、套用、重命名、删除交互
```

若实施中为了复用需导出 `storage.ts` 的草稿校验器，只能导出纯校验函数，不得放宽现有输入边界。Chrome 61 兼容 ID 回退继续使用现有实现，不新增网络、IndexedDB 封面或现代 API 强依赖。

- 实现目录严格解析、独立错误状态和原子式“先校验/序列化、后单次 setItem”。

### V03-TPL-03：移动界面与启动接线

- 增加紧凑模板面板、模板名输入、保存/套用/重命名/删除操作和双语状态文案。

- 加分项支持新增与删除，边界为 1–12 项；操作后进入自定义模式。标题、按钮、帮助、状态与读屏名称只描述评分语义，不描述图标外形。
- 360 px 宽度下所有操作可触控、无横向滚动；确认框只用于会覆盖或删除数据的操作。

### V03-TPL-04：回归与证据

- 单元/组件测试覆盖存储和交互；最终 `file://` E2E 覆盖首次启动、重开恢复、保存及套用。
- 执行格式、Lint、类型、全量单元测试、小工具 E2E、构建、最终产物审计和打包。
- 生成 M2.1 执行记录、ZIP 文件清单和 SHA-256；真实容器测试继续与桌面 Chromium 证据分开标注。
