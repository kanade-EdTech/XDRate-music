## 1. 实施结论

- 窗口标题使用“作品名或文件名 + 未保存星号 + XDRate Music”，只取文件基名，不把完整本地路径放入标题；保存失败继续保留星号，保存成功才移除。
- 桌面模式提供 `Ctrl+N`、`Ctrl+O`、`Ctrl+S`、`Ctrl+Shift+S`、`Ctrl+Shift+E`、`Ctrl+Q`，分别对应新建、打开、保存、另存、导出 PNG、退出；可见按钮继续保留并提供 `aria-keyshortcuts` 与双语提示。
- 输入框聚焦时只拦截上述明确命令，不拦截复制、粘贴、剪切、撤销、重做、全选或普通输入。新建/打开/退出仍复用未保存修改保护，取消后归还焦点且不改变文字。
- 最近文件最多保存 10 条本地显示元数据，按规范化路径去重并把最新项置顶；不保存文件内容，不扫描目录，不自动打开路径，可单条移除或清空。
- 自动草稿和用户磁盘文件严格分离。异常会话启动时先显示作品名、已评分分项数和正文摘要；用户明确选择“恢复此草稿”或“放弃并新建”后才进入编辑。恢复只载入内存，不写入或覆盖磁盘文件。

## 2. 状态与恢复契约

| 场景           | 标题/状态                                           | 恢复标记       |
| -------------- | --------------------------------------------------- | -------------- |
| 新建空白       | `未命名评价 — XDRate Music`                         | 已处理         |
| 编辑           | `作品名 * — XDRate Music`                           | 自动草稿待恢复 |
| 打开文件       | `作品名 — XDRate Music`；作品名为空时仅显示文件基名 | 已处理         |
| 保存成功       | 移除 `*`                                            | 已处理         |
| 保存取消或失败 | 保留 `*` 和当前内容                                 | 保持待恢复     |
| 异常重启       | 先显示恢复摘要，不静默采用                          | 由用户决定     |

恢复对话框初始焦点在“恢复此草稿”，焦点在两个决策按钮之间循环。恢复决策未完成前暂停新的自动保存，避免空白初始界面覆盖恢复副本。

## 3. 权限与隐私边界

- 新增的 Tauri 权限只有 `core:window:allow-set-title`；与既有 `allow-native-files`、`core:window:allow-close` 合并使用。
- 未增加 shell、进程、任意文件系统、网络、遥测或 updater 权限。
- 最近文件存储键为 `xdrate.music.recent-files.v1`，仅包含显示名、用户已选择的路径和最近打开时间。
- 恢复状态键为 `xdrate.music.recovery-state.v1`；评价内容仍使用现有本地工作区存档，不创建隐藏磁盘副本。

## 5. 最小人工验收

在 Windows 10/11 x64 安装包中分别切换简体中文和 English：

1. 查看新建、编辑、保存成功及模拟保存取消后的窗口标题；确认没有完整路径。
2. 在作品名输入框中输入一段文字，依次验证六条快捷键及可见按钮；取消受保护操作后文字和焦点仍在。
3. 打开并保存两个存档，确认最近文件顺序；移动其中一个文件后，从列表显式移除该条目并清空列表。
4. 编辑后直接结束应用进程，再启动；先核对摘要，再分别验证恢复与放弃，确认原磁盘文件未被覆盖。
