# V0.3.1 M4 真机验收与发布计划

状态：待执行；RC.1 已冻结，公开发布仍被真实容器、真机、权限和读屏门禁阻塞

日期：2026-09-07

## 1. 目标与边界

本计划把 v0.3.1 M4 从“自动化与静态审计通过的工程候选”推进到“可作发布决定的真机候选”。验收只覆盖用户主动生成评分卡、保存到相册，以及明确确认后把图片与文字移交小红书原生发帖流程。

以下事项不在本轮承诺范围内：后台或自动发布、证明帖子已经公开、读取手机相册、远程服务、账号体系，以及对未记录平台版本的兼容性承诺。`postNote` 返回受理只代表进入原生发布流程。

## 2. 唯一送测输入

所有平台必须测试完全相同的候选包，中途不得编辑、解压后修改或重新压缩。

测试前先核对 SHA-256 sidecar 与机器可读清单。任何包内字节变化都会使 RC.1 证据失效，并触发第 7 节的重发流程。

## 3. 执行顺序

| 阶段 | 平台                     | 主要目的                                    | 进入下一阶段的条件           |
| ---- | ------------------------ | ------------------------------------------- | ---------------------------- |
| P0   | 本地完整性检查           | 核对 ZIP、哈希、清单和来源提交              | 四项完全一致                 |
| P1   | 小红书官方 PC 模拟器     | 尽早发现入口、Bridge、CSP 和基础交互问题    | 核心流程无阻塞缺陷           |
| P2   | Android 8.1 / WebView 61 | 验证最低兼容基线、软键盘、触控与旧容器      | 核心流程、相册和发帖回退可用 |
| P3   | 当前 Android             | 验证当前容器、权限恢复、TalkBack 与生命周期 | 权限矩阵和读屏通过           |
| P4   | iOS 18.4+                | 验证安全区、照片权限、VoiceOver 与原生返回  | 权限矩阵和读屏通过           |
| P5   | 合并复核                 | 汇总证据、已知限制和发布文案                | 所有阻塞项关闭或明确停止发布 |

P1 失败时先停止后续测试并分类；P2 的最低兼容问题属于发布阻塞。P3/P4 的平台专属问题可在完成影响评估后决定修复或缩小支持范围，但不得静默忽略。

## 5. 证据管理

原始证据建议放在不提交 Git 的目录：

```text
artifacts/minitool/v0.3.1-rc.1-acceptance/
  pc-simulator/
  android-8.1/
  android-current/
  ios-18.4-plus/
```

文件名使用 `平台_用例ID_日期_序号`，例如 `android-current_POST-02_20260907_01.mp4`。仓库文档只记录去标识化结论和必要哈希，不提交账号、头像、设备序列号、通知内容、私人照片或未授权作品。

## 6. 角色与交接

- 测试执行者：在真实设备安装同一 RC.1、执行用例并记录原始证据。
- 开发：复现和分类失败，维护修复、自动化、候选包与变更记录。
- 发布负责人：核对矩阵、隐私边界和已知限制，作出发布、修复后重测或停止发布的结论。

发现问题时记录：平台、用例 ID、复现步骤、期望、实际、频率、证据文件和是否阻塞；不要只写“有问题”或“没问题”。

## 7. 失败与新候选策略

1. 只要源码、构建配置或 ZIP 内容变化，立即作废 RC.1 的后续发布资格。
2. 禁止直接修改或重新压缩 RC.1；修复必须进入 Git，并增加修复测试。
3. 生成 `v0.3.1-rc.2`（或更高序号）、新清单和新 SHA-256，再从 P0 开始。
4. 通用逻辑、评分卡或 Bridge 改动需要重跑全部平台；纯平台修复至少重跑受影响平台，并在 P5 评估是否需要全矩阵复测。
5. 若确认是平台能力缺失，文档必须写清受影响版本与降级行为；不能用自动化模拟结果替代真机结论。

## 8. 发布完成定义

只有同时满足以下条件，才能把 `V031-M4-01` 标记为完成并准备公开发布：

- P0–P5 均完成，四个平台记录无空项；
- 相册允许/拒绝/取消/恢复和发帖受理/取消/失败/返回矩阵通过；
- TalkBack 与 VoiceOver 的关键流程证据完成；
- 11 比例无溢出，预览、保存和提交使用同一评分卡图片；
- 未发现第三方网络请求或超出清单的 Bridge 能力；
- 发布说明明确“受理不等于公开发布”，并列出真实已知限制；
- 最终上传的 ZIP 与本计划冻结哈希一致，或已用新 RC 文档完整替代。

若任一阻塞项未关闭，结论保持“工程候选，可继续送测，不可公开发布”。
