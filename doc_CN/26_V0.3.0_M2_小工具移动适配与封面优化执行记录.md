## 2. 封面压缩策略

- 输入仅接受 PNG、JPEG、WebP；单文件大于 20 MiB 时在解码前拒绝，避免明显的内存峰值。
- 使用 `URL.createObjectURL()` 加载原图，完成解码后立即释放原始 URL。
- 采用 Canvas 2D 等比缩放，首选最长边 1280 px；必要时依次降到 1024 与 768 px。
- 优先 WebP，质量档为 0.84、0.72、0.60；目标输出不超过 512 KiB，并保留最小成功结果作为兜底。
- 预览只持有压缩后 Blob URL；替换、移除或组件卸载时释放。Canvas 编码后重置为 1×1，尽快归还像素缓冲。
- UI 明确显示输出尺寸、KiB 与 MIME 类型；类型错误、超过 20 MiB、解码失败和编码失败均有可恢复反馈。
- M2 不把封面 Base64 写入 localStorage；重开后需重新选择封面。这是内存保护边界，不冒充永久备份。

## 3. 触控、软键盘与安全区

- 加分与扣分控件使用单行弹性布局；正向评分点击区高度 55 CSS px，轴名输入宽度维持紧凑比例，360 px 视口无需横向拖动。
- 所有表单和关键按钮至少 44 CSS px 高，触摸态默认可见，不依赖 hover。
- `visualViewport` 存在时维护 `--app-height` 与 `--keyboard-offset`；不可用时回退到 `window.innerHeight`。
- 只有布局高度与视觉视口相差至少 120 px 时才判定软键盘开启，避免把小幅浏览器栏变化误判为键盘。
- 表单获得焦点后延迟 180 ms 滚动到可视中心；旧实现不支持对象参数时回退到 `scrollIntoView(false)`。
- 宽度明显变化时重建视口基线，避免横竖屏切换继续沿用旧方向高度。
- 安全区先保留普通 padding，再使用 `var(--safe-area-inset-*, env(..., 0px))` 组合；PC 模拟器注入变量和真机 `env()` 均有路径。
- 键盘开启时自动保存状态条保持粘性可见，页面底部增加键盘偏移量以便最后一个输入框滚出遮挡区。
