+# 数据模型与存档格式

## 1. 设计规则

- JSON 字段使用英文 `camelCase`，枚举使用稳定英文值。
- 每个可独立迁移的文件必须带 `schemaVersion`。
- ID 使用 UUID v4；不得用用户可编辑名称作为唯一键。
- 时间使用 ISO 8601 UTC 字符串；界面显示时再本地化。
- `null` 表示明确无值，可选字段缺失表示旧版本或未提供；Schema 必须说明两者。
- 星星和香蕉皮不新增图标计数字段。正向分数为 `integer`，其中 `0` 是“未评分”哨兵，有效评分为整数 1–10；扣分仍为支持小数的 -5–0。Schema 保持 v2，算法保持 `music-linear-100-v4`。

## 2. 核心 TypeScript 模型

```ts
type RatingMode = 'simple' | 'professional' | 'custom';
type ThemeId = 'light' | 'dark';
type CardRatio =
  '16:9' | '8:5' | '3:2' | '4:3' | '5:4' | '1:1' | '4:5' | '3:4' | '2:3' | '5:8' | '9:16';

interface RatingAxis {
  id: string;
  name: string;
  score: number; // 0 = unrated; otherwise 1..10
  importanceLevel: 0 | 1 | 2 | 3 | 4 | 5 | 6;
  enabled: boolean;
  reason: string;
}

interface NegativeItem {
  id: string;
  name: string;
  score: number; // -5..0
  enabled: boolean;
  reason: string;
}

interface WorkMetadata {
  title: string;
  artistLabel: string | null;
  artist: string;
  albumLabel: string | null;
  album: string;
  extraFields: WorkMetadataEntry[];
  releaseYear: string;
  coverDataUrl: string | null;
}

interface WorkMetadataEntry {
  id: string;
  label: string;
  value: string;
}

interface CardOptions {
  themeId: ThemeId;
  ratio: CardRatio;
  pixelRatio: 1 | 2;
  showCover: boolean;
  showReasons: boolean;
  showStory: boolean;
  hideEmptyFields: boolean;
}

interface MusicRating {
  id: string;
  schemaVersion: 1;
  algorithmVersion: 'music-linear-100-v4';
  mode: RatingMode;
  work: WorkMetadata;
  axes: RatingAxis[];
  negativeItems: NegativeItem[];
  overallComment: string;
  personalStory: string;
  card: CardOptions;
  createdAt: string;
  updatedAt: string;
}
```

`artistLabel` 与 `albumLabel` 使用三态语义：`null` 表示编辑器采用当前语言的默认“艺术家 / Artist”或“专辑 / Album”，但卡片只显示内容；非空且不等于任何受支持语言默认名称的字符串表示自定义名称，并在卡片显示“名称：内容”；空字符串表示明确省略名称，也只显示内容。编辑器把重新输入的本地化默认名称归一化为 `null`；卡片渲染层同时过滤旧草稿中已保存的默认名称字符串。`extraFields` 最多 6 项；名称最长 24 字符、内容最长 120 字符，内容非空时按“名称：内容”进入卡片。上述字段随草稿和完整存档保存；模板不包含作品信息，因此不携带这些字段。

## 3. 完整存档

```ts
interface RatingArchiveV2 {
  format: 'xdrate-music-archive';
  schemaVersion: 2;
  algorithmVersion: 'music-linear-100-v4';
  exportedAt: string;
  appVersion: string;
  workspace: {
    rating: MusicRating;
    cardOptions: CardOptions;
  };
}
```

约束：

- `axes`：1–12 项；启用项 1–12 项。
- `negativeItems`：0–5 项。
- 存档总导入上限建议为 8 MB。
- 封面以 `rating.work.coverDataUrl` 保存，可为 `null`。

## 4. 模板格式

```ts
interface RatingTemplateV2 {
  format: 'xdrate-music-template';
  schemaVersion: 2;
  algorithmVersion: 'music-linear-100-v4';
  id: string;
  name: string;
  mode: RatingMode;
  axes: Array<Pick<RatingAxis, 'id' | 'name' | 'importanceLevel' | 'enabled'>>;
  negativeItems: Array<Pick<NegativeItem, 'id' | 'name' | 'enabled'>>;
  card: Omit<CardOptions, 'pixelRatio'>;
  createdAt: string;
  updatedAt: string;
}
```

模板加载后，正向分数初始化为 `0`（未评分），负面分数初始化为 0，理由和正文初始化为空。

## 5. 用户偏好

```ts
interface UserPreferencesV1 {
  schemaVersion: 1;
  locale: 'zh-CN' | 'en';
  appTheme: 'system' | 'light' | 'dark';
  lastMode: RatingMode;
  defaultImportanceLevel: 0 | 1 | 2 | 3 | 4 | 5 | 6;
  defaultCardOptions: CardOptions;
}
```

默认重要等级为 LV3（×1.00）。修改某一评价的单个轴不应自动改变全局默认；只有用户明确选择“设为以后默认”时才更新偏好。

## 6. 校验与迁移

导入校验分为：

1. **容器校验**：格式标识、主版本、大小。
2. **结构校验**：必填字段、类型、枚举、数组长度。
3. **语义校验**：范围、唯一 ID、引用完整性、至少一个可计算轴。
4. **净化**：去除未知字段或放入扩展区，清理不可见控制字符。

迁移函数必须是纯函数、可重复执行且有基于固定夹具的测试。迁移前保留原始导入对象，迁移失败不得部分写入存储。

v1 → v2 迁移规则：

| v1 值      | v2 值  |
| ---------- | ------ |
| `wide`     | `16:9` |
| `square`   | `1:1`  |
| `portrait` | `4:5`  |

迁移同时写入 `algorithmVersion: 'music-linear-100-v4'`。导入存档时，旧 `score = 0` 保持为“未评分”，任意正向小数分四舍五入并限制到最近的 1–10 整星（例如 7.4 → 7、7.5 → 8）；既有整数评分保持不变。旧 v2 作品信息中的空 `albumLabel` 迁移为 `null`，并补 `artistLabel: null` 与 `extraFields: []`，从而继续显示本地化默认名称。浏览器优先读取自描述的 `workspace.v2` / `templates.v2`；若不存在则只读回退到 v1 键，旧键不删除。高于当前版本的存档和模板必须拒绝。
