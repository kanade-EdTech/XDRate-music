# V0.3.0 M2.1 最近草稿与内容模板执行记录

## 1. 结论

M2.1 已实现最近完整草稿优先恢复、一次性《海棠仙》普通模板播种、本地内容模板管理，以及 1–12 个加分项的新增/删除。《海棠仙》没有只读或内置权限，可被覆盖、改名和删除；独立播种标记不会随模板删除，自动化已证明删除模板并移除最近草稿后，重新打开会得到空白简易草稿而不是复活《海棠仙》。

这些证据来自单元测试和桌面 Chromium 对最终 `file://` 产物的验收，不代表真实小红书 Android/iOS 宿主已经完成缓存寿命、输入法、后台恢复或系统清理验证。

## 2. 实现范围

- 新增稳定、无封面的《海棠仙》种子夹具，固定 8/7/9 整数评分、LV3、三项理由、作品字段和故事，综合分断言为 80.0。
- 最近草稿、模板目录和一次性播种标记使用三个独立键并分别校验；有效最近草稿始终优先。
- 首次目录写入成功后才记录播种完成；初始化重试通过稳定模板 ID 去重。已播种且没有最近草稿时创建空白简易草稿。
- 内容模板保存作品、分项整数评分、理由、扣分项和正文，但始终把封面清为 `null`。封面 Blob 仍只存在内存。
- 支持新建、同名覆盖确认、套用确认、重命名和删除确认；模板名 1–40 字符、最多 20 项、目录最大 512 KiB，并按更新时间降序。
- 增加页面隐藏/关闭前的最近草稿尽力同步保存，同时保留原 300 ms 防抖。
- 中文和英文模板面板均说明本地缓存不是永久存储；360 CSS px 下按钮至少 44 px 高且没有横向滚动。
- 正向加分项支持新增、改名、整数评分和删除，数量限制为 1–12 项；增删会进入自定义模式，未评分项继续不计入综合分。
- 用户可见标题、按钮、帮助、状态和无障碍名称只使用“加分项 / 评分 / 扣分项 / 扣分”等中性词，不描述图标外形。
- 生成区及 PNG 本身均标明当前输出只是“非正式链路测试图”；正式 11 比例评分卡仍属于 M3，未在本记录中虚报完成。
