## 1. 文档目的

本目录把仓库中的早期构思整理为可执行、可测试、可维护的开发规范。当前阶段只实现音乐评价工具；动漫、游戏及政治相关评分均不属于 v0.1 范围。

## 2. 产品一句话说明

多维音乐评价（`XDRate Music`）是一款开源、离线优先的多维音乐评价与图片生成工具：用户输入作品信息，按自定义维度评分、填写评价与故事，然后导出适合分享的评价卡片。

> 音乐产品的正式双语名称为“多维音乐评价” / `XDRate Music`。未来垂直产品沿用“多维{领域}评价” / `XDRate {Domain}` 命名规则，详见[决策记录](./08_决策记录与待确认项.md)。

## 5. 当前基线

- 版本目标：Web v0.1（收口） / Desktop v0.2（M4 工程完成，公开 RC 待门禁） / Xiaohongshu MiniTool v0.3.0（M4 静态预检完成，公开 RC 待门禁） / Standalone Mobile v0.4（顺延）
- 技术基线：React + TypeScript + Vite + Tailwind CSS + Tauri 2
- 算法模型：`music-linear-100-v4`（0–100 分综合分；未评分轴不作数，最低一星）
- 数据架构：Archive Schema v2，浏览器本地存储与 JSON 导入/导出，零后端
- 卡片排版：11 种比例、4 大布局族、内容感知多状态自适应布局、确定性降级防溢出门禁
- 图片导出：`html-to-image`（2× 物理分辨率 PNG）
- 质量保证：Vitest 143/143、小工具定向单测 24/24、Rust 8/8、Playwright 三浏览器 48/48、小工具 E2E 16/16、卡片视觉 3/3、桌面视觉 5/5、视觉交接 2/2 通过
- 许可：MIT；用户内容遵循免责声明
- 语言：完整支持简体中文与 English（i18n 消息键驱动）
- 发布：Windows 10/11 x64；正式包强制 Authenticode + RFC 3161 时间戳；`0.2.0` 手动更新
- 桌面状态：M4 安全、离线/导航、自动化和文档已完成；当前 NSIS 候选仍未签名并使用开发图标，Windows 10/11 干净安装矩阵及读屏复核待执行
- 小工具状态：M4 静态预检包已通过解包目录及最终 ZIP 双重审计、逐字节一致性校验与 2 MiB 预算；Chromium `file://` 自动化 16/16。当前来源树尚未提交，Android 8.1/WebView 61、当前 Android、iOS 18.4+、小工具读屏及精确包相册权限矩阵仍阻塞公开 RC
