# V0.2 交付与故障排查指南

适用版本：XDRate Music `0.2.0`  
支持平台：Windows 10/11 x64  
发布者：科魂老师 / `Kehun_EdTech`

## 1. 安装与首次启动

公开 RC/Stable 只从官方 XDRate GitHub Releases 获取，并核对同页 SHA-256。正式安装器必须通过 Windows 数字签名属性或以下命令验证：

```powershell
Get-AuthenticodeSignature '.\XDRate Music_0.2.0_x64-setup.exe' | Format-List
Get-FileHash '.\XDRate Music_0.2.0_x64-setup.exe' -Algorithm SHA256
```

状态必须为 `Valid`，签名者应与发布清单一致。当前开发/内部候选可能未签名，不能作为 Stable 分发。安装后从开始菜单启动；Windows 10/11 通常已包含 WebView2，若提示缺少组件，请通过 Microsoft 官方渠道安装 WebView2 Runtime。

## 2. 打开、保存与另存

- `Ctrl+O`：打开 `.xdrate.json`；
- `Ctrl+S`：保存到当前文件；尚无当前文件时自动进入“另存为”；
- `Ctrl+Shift+S`：另存为；
- `Ctrl+N`：新建评价；
- `Ctrl+Shift+E`：保存 PNG；
- `Ctrl+Z` / `Ctrl+Shift+Z`：撤销 / 重做。

标题栏的 `*` 和界面保存状态表示尚未写入当前存档的修改。新建、打开其他文件或关闭应用时，如果存在未保存修改，必须选择保存、放弃或取消。自动草稿不能替代磁盘存档。

## 3. 从 Web 版迁移

桌面版不会读取浏览器 localStorage。请在 Web 版导出完整 `.xdrate.json`，然后在桌面版使用“打开”。存档仍为 Archive Schema v2，不写入本机路径；完成编辑后仍可回到兼容的 Web 版导入。

## 4. 备份与失败恢复

1. 重要评价定期“另存为”到另一个目录或备份介质；
2. 异常退出后重启，按恢复提示检查本地恢复状态；
3. 恢复内容确认无误后立即保存为 `.xdrate.json`；
4. 保存失败时不要反复覆盖原文件，先另存到确认可写的目录；
5. 损坏、超限、未知高版本存档会被拒绝，当前工作区不会因此被替换。

文件写入采用同目录临时文件与原子替换；失败时应保留旧文件。云盘、杀毒软件或权限策略仍可能阻止写入，遇到此情况请改存到本地“文档”目录并保留原件。

## 5. PNG 与图片问题

封面仅支持 JPEG、PNG、WebP，最大 10 MB，文件内容必须与格式一致。PNG 导出前若显示溢出警告，应缩短极长文本、减少条目或改用更适合内容的比例。预览与导出使用同一布局计划；若只在导出中异常，请记录比例、缩放、主题和复现文本。

## 6. 隐私与联网

应用无账号、无遥测、无远程字体、无后端，也不包含 `0.2.0` 内置更新器。评价、图片和恢复状态留在本机，只有用户主动保存/复制文件时才离开应用。用户应确保拥有所用封面和文字的权利。

## 7. 卸载与数据保留

卸载程序文件不等同于删除用户自行保存的 `.xdrate.json` 和 PNG。正式发布前必须在 Windows 10/11 干净快照确认：覆盖升级保留本地偏好/恢复数据，卸载行为与安装器说明一致。需要彻底清理时，先备份存档，再按发布说明删除应用本地数据；不要把手动保存的作品文件当作缓存删除。

## 8. 常见故障

| 现象             | 建议操作                                                     |
| ---------------- | ------------------------------------------------------------ |
| 无法启动/白屏    | 重启应用；确认 WebView2；记录 Windows 版本与事件查看器信息   |
| 打开存档失败     | 检查扩展名、16 MiB 上限与存档来源；保留原件，不手工覆盖      |
| 保存失败         | 改用“另存为”到本地可写目录；检查只读、云盘同步和安全软件     |
| PNG 保存失败     | 检查目标目录权限与可用空间，换新文件名重试                   |
| 字体或布局异常   | 记录系统缩放、显示器、主题、比例和截图；先恢复 100% 缩放复核 |
| 恢复提示内容不对 | 取消覆盖，先导出/另存当前可见内容，再报告复现步骤            |

报告问题时请提供应用版本、Windows 版本、操作步骤、错误文案、是否可在新建评价复现；不要提交含私人正文或未授权封面的存档。
