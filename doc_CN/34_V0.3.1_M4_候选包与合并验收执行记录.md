# V0.3.1 M4 候选包与合并验收执行记录

状态：M4 工程候选与精确 RC.1 送测包完成；公开发布受真实容器、真机和读屏门禁阻塞

日期：2026-09-07

分支：`codex/v0.3.1-post-note`

## 1. 阶段决策

产品负责人决定跳过独立 M3 并直接进入 M4。该决定没有把 M3 标记为验收通过，也没有删除其质量要求。正式评分卡接入、11 比例预览/提交一致性、无障碍名称、焦点恢复和回退路径已作为 M4 合并门禁执行。

## 2. M4 交付

- 用户界面使用正式 `MINI TOOL v0.3.1` 标识，不显示内部 M2/M3/M4 标签。
- 确认页打开后焦点进入帖子标题；原生取消或失败后焦点返回“去小红书发布”按钮。
- 新增 11 种比例逐一生成、确认和提交的 E2E，验证每次交给 `postNote` 的 PNG Data URI 与确认页当前图片完全相同。
- 确认页执行完整 Axe 自动扫描；自动化结果为零违规。
- 打包命令、默认文件名和最终校验器切换到独立 v0.3.1 命名空间，不覆盖 v0.3.0 RC.1。
- v0.3.1 清单如实列出 `writeTempFile`、`saveImageToPhotosAlbum` 和 `postNote`，并把发布能力描述为“用户确认后移交小红书原生发帖流程”，不宣称公开发布。
