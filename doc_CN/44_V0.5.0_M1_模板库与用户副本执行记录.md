# V0.5.0 M1 模板库与用户副本执行记录

状态：M1 页面接入完成；完整评分编辑待 M2

日期：2026-09-25

## 已完成

- 新增 `src/domain/game/templateCatalog.ts`，提供四个游戏示例模板。
- 示例内容来自 `模板/游戏评分器模板.md`，已登记红色警戒 2、使命召唤 4、原神、黑神话：悟空的个人评分、分项理由、模式和评价轴。
- 模板引用 OpenCV 处理后的 1024×1024 WebP 封面，不直接修改原始 PNG。
- 实现模板套用、复制为用户模板、改名和删除。
- 所有套用/复制操作执行深拷贝；用户修改不会回写 `seeded-example`。
- 模板名称为空或 ID 不存在时返回明确错误。
- 新增 `src/domain/game/templateStorage.ts`，实现一次播种、恢复、大小限制、重复 ID/名称校验和损坏数据拒绝。
- 游戏模板使用独立本地存储键；清除工作区不会删除模板目录。
- 新增 `GameRatingPilot` 独立试验入口，使用 `?domain=game` 进入，不覆盖音乐主线。
- 页面已接入封面、示例标识、套用、复制、改名、删除和当前副本摘要。

## 当前未完成

- 当前页面只展示套用后的评分摘要，尚未实现完整的游戏作品信息和评分编辑控件。
- 尚未把 WebP 资源转为编辑器现有的 `coverDataUrl` 输入。
- 四张封面仍为 `pending-rights-review`；在版权结论明确前不进入公开 Toy 包。
- 平台、版本和发行信息仍需由模板内容或用户补充，当前不凭空填充。

- `npx vitest run src/domain/game/presets.test.ts src/domain/game/templateCatalog.test.ts`：6/6 通过。
