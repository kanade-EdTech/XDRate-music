# V0.2 Delivery and Troubleshooting Guide

Applies to: XDRate Music `0.2.0`  
Supported platform: Windows 10/11 x64  
Publisher: 科魂老师 / `Kehun_EdTech`

## 1. Install and first launch

Obtain a public RC/Stable only from the official XDRate GitHub Releases page and compare its SHA-256. A public installer must pass:

```powershell
Get-AuthenticodeSignature '.\XDRate Music_0.2.0_x64-setup.exe' | Format-List
Get-FileHash '.\XDRate Music_0.2.0_x64-setup.exe' -Algorithm SHA256
```

Status must be `Valid`, and the signer must match the release manifest. Development/internal candidates may be unsigned and must not be distributed as Stable. Launch from Start. If WebView2 is missing, install the runtime through an official Microsoft channel.

## 2. Open, save, and Save As

- `Ctrl+O`: open `.xdrate.json`;
- `Ctrl+S`: save; without a current file it opens Save As;
- `Ctrl+Shift+S`: Save As;
- `Ctrl+N`: new rating;
- `Ctrl+Shift+E`: save PNG;
- `Ctrl+Z` / `Ctrl+Shift+Z`: undo / redo.

An asterisk in the title and the in-app save state mean there are changes not written to the current archive. New, Open, and Close must offer Save, Discard, or Cancel when dirty. Autosave is not a disk archive.

## 3. Migrate from Web

The desktop app does not read browser localStorage. Export a complete `.xdrate.json` in Web, then use Open in Desktop. Archives remain Schema v2 and contain no native path, so they can be imported back into a compatible Web version.

## 4. Backup and recovery

1. Regularly use Save As to another directory or backup medium;
2. after an abnormal exit, restart and inspect the local recovery prompt;
3. after confirming recovered content, save it immediately as `.xdrate.json`;
4. after a save failure, use Save As to a known writable directory instead of repeatedly overwriting;
5. corrupt, oversized, or unknown-future archives are rejected without replacing the current workspace.

Writes use a sibling temporary file and atomic replacement, preserving the old file on failure. Cloud sync, antivirus, or policy can still block writes; try a local Documents folder and retain the original.

## 5. PNG and image issues

Covers support JPEG, PNG, and WebP up to 10 MB, with content matching the declared type. If export reports overflow, shorten extreme text, reduce entries, or choose a ratio better suited to the content. Preview and export share one layout plan; if only export fails, record ratio, scaling, theme, and reproduction text.

## 6. Privacy and networking

There are no accounts, telemetry, remote fonts, backend, or built-in `0.2.0` updater. Ratings, images, and recovery state stay local until the user saves or copies a file. Users remain responsible for rights to covers and text.

## 7. Uninstall and retained data

Removing program files is not the same as deleting user-saved `.xdrate.json` and PNG files. Before public release, clean Windows 10/11 snapshots must prove that in-place upgrades preserve intended preferences/recovery data and uninstall matches the installer notice. Back up archives before manually removing app-local data, and never treat user-saved work files as cache.

## 8. Troubleshooting

| Symptom                     | Action                                                                              |
| --------------------------- | ----------------------------------------------------------------------------------- |
| launch fails/blank window   | restart; verify WebView2; record Windows version and Event Viewer detail            |
| archive will not open       | check extension, 16 MiB limit, and source; retain the original                      |
| save fails                  | Save As to a local writable directory; check read-only, sync, and security software |
| PNG save fails              | check target permission/free space and retry with a new name                        |
| font/layout issue           | record scaling, display, theme, ratio, and screenshot; recheck at 100%              |
| unexpected recovery content | cancel replacement, save visible content elsewhere, then report steps               |

Issue reports should include app/Windows version, steps, exact error, and whether a new rating reproduces it. Do not submit private text or an unlicensed cover.
