# V0.5.0 M1 Template Library and User-Copy Execution Log

Status: M1 page wiring complete; full rating editing moves to M2

Date: 2026-09-25

## Completed

- Added `src/domain/game/templateCatalog.ts` with four game example templates.
- Loaded personal scores, reasons, modes, and axes from `模板/游戏评分器模板.md` for Red Alert 2, Call of Duty 4, Genshin Impact, and Black Myth: Wukong.
- Templates reference the OpenCV-processed 1024×1024 WebP covers without modifying the original PNGs.
- Implemented apply, copy as a user template, rename, and delete operations.
- Apply/copy always deep-clone; user edits cannot mutate a `seeded-example`.
- Empty names and unknown IDs return explicit errors.
- Added `src/domain/game/templateStorage.ts` for one-time seeding, restore, size limits, duplicate ID/name validation, and corrupt-data rejection.
- Game templates use an isolated local-storage key; clear-all does not delete the template library.
- Added an independent `GameRatingPilot` entry at `?domain=game` without replacing the music mainline.
- The page now displays covers, example labels, apply, copy, rename, delete, and a current-copy summary.
