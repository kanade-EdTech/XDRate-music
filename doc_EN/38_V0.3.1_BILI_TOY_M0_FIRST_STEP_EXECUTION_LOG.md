## 5. Preview issue fix

The first online preview lost global styling: browser-default form controls, broken rating layout, and an oversized radar graphic were visible. The cause was Tailwind CSS being injected at runtime inside JavaScript, which the Toy container did not apply.

The Toy build now emits an explicit `assets/style.css` loaded from the root `index.html` with a relative path. Corrected local result: 3 files, 421,063 bytes, 0 errors. The old preview is invalid and must be regenerated before acceptance.
